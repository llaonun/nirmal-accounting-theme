# Nirmal Accounting

A professional WordPress theme for online accounting, bookkeeping, VAT/TDS and payroll compliance services in Nepal. Clean navy-and-gold design with services, pricing, FAQ, testimonials and WhatsApp-first contact sections.

- **Version:** 1.0.0
- **Author:** Nirmal Kumar Bhattarai
- **License:** MIT

## Install

1. Download or clone this repository.
2. Copy the folder into `wp-content/themes/` on your WordPress site.
3. Activate it in WordPress admin (Appearance > Themes).
